# Architecture Decisions

Architecture decision records document important design choices and their
rationale. A record may have one of these statuses:

- Proposed: under consideration and not yet implemented.
- Accepted: chosen for implementation.
- Implemented: present in the application.
- Superseded: replaced by a later decision.
